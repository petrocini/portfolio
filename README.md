# Portfólio — Lucas Petrocini

Landing page pessoal para apresentar experiência profissional, serviços de desenvolvimento full stack e cases selecionados.

## Stack

React, TypeScript, Vite e CSS.

## Executar localmente

```bash
npm install
npm run dev
```

Opcionalmente, copie `.env.example` para `.env.local` e defina `VITE_WHATSAPP_NUMBER` para ativar o contato pelo WhatsApp.

## Comandos

```bash
npm run lint
npm run test
npm run build
```
